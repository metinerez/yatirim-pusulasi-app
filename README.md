# Yatırım Pusulası (masaüstü)

Fon, hisse, emtia ve coin portföyünü izleyen, Windows'a kurulan kişisel yatırım uygulaması.

- Portföy verileri yalnızca kullanıcının bilgisayarında saklanır; bu depoda kişisel veri yoktur.
- Veriler herkese açık kaynaklardan çekilir: TEFAS, KAP, İş Yatırım, Yahoo Finance.
- Kurulum dosyası **Releases** bölümündedir. 1.4 ve sonrası yeni sürümleri kendisi indirir.

Sinyaller ve taramalar kurallara dayalı göstergelerdir; yatırım tavsiyesi değildir.
